# Asset Management System

A full-stack Asset & Inventory Management System built using Django REST Framework and React.

## Features
- JWT-based authentication (Admin & Employee roles)
- Asset management (CRUD)
- Inventory tracking
- Asset assignment to employees
- Repair ticket raising and status tracking
- Dashboard with asset and ticket counts
- Role-based access control

## Tech Stack
- Frontend: React, Axios, React Router, CSS
- Backend: Django, Django REST Framework, Simple JWT
- Database: SQLite 
- Hosting: Render (Backend + Frontend)
